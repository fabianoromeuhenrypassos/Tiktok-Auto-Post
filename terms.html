Termos de Uso — Pensamento Phixel

Última atualização: 8 de agosto de 2026.

O Pensamento Phixel é uma ferramenta de automação de uso pessoal, desenvolvida e operada por Fabiano Passos, com a única finalidade de publicar vídeos na conta própria do TikTok do operador por meio da Content Posting API oficial do TikTok.

Uso permitido

Este app é de uso exclusivamente pessoal e não é disponibilizado publicamente para outros usuários. Ele não deve ser usado para publicar conteúdo que viole os Padrões da Comunidade do TikTok ou os Termos de Serviço para Desenvolvedores do TikTok.

Responsabilidade

O operador é o único responsável pelo conteúdo publicado através deste app. O app apenas automatiza o envio de arquivos de vídeo já preparados pelo operador; não gera, modifica nem seleciona conteúdo de forma autônoma.

Disponibilidade

Por se tratar de uma ferramenta pessoal, não há garantia de disponibilidade contínua, suporte formal ou SLA. O funcionamento depende da disponibilidade da API do TikTok.

Alterações

Estes termos podem ser atualizados a qualquer momento. A versão vigente é sempre a publicada nesta página.
