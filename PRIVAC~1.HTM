Política de Privacidade — Pensamento Phixel

Última atualização: 8 de agosto de 2026.

O Pensamento Phixel é uma ferramenta de uso pessoal, criada e operada por Fabiano Passos, que automatiza a publicação de vídeos na conta própria do TikTok do desenvolvedor. Este app não é distribuído a terceiros e não coleta dados de nenhum outro usuário além do próprio operador.

Quais dados são acessados

O app utiliza a Content Posting API do TikTok para publicar vídeos na conta autorizada. Os únicos dados tratados são:

  • Access token e refresh token do OAuth do TikTok, necessários para autenticar as chamadas de API;
  • Informações públicas do criador (nome de usuário, opções de privacidade disponíveis), retornadas pela própria API do TikTok para configurar corretamente cada publicação;
  • Arquivos de vídeo fornecidos pelo próprio operador, armazenados localmente antes do envio.

Como os dados são armazenados

Tokens e vídeos permanecem exclusivamente em ambiente local controlado pelo operador. Nenhum dado é compartilhado, vendido ou transmitido a terceiros. Nenhum servidor externo além da própria API oficial do TikTok é utilizado.

Retenção e exclusão

Os tokens podem ser revogados a qualquer momento pelo operador diretamente nas configurações de apps conectados da conta TikTok, ou removendo os arquivos locais de configuração.
